# Sales Data Analysis Using Oracle SQL

## Project Overview
This is a beginner-level Sales Data Analysis project using Oracle SQL. The project focuses on analysing sales data to understand product performance, revenue generation, city-wise sales, and monthly sales trends.

## Tools Used
- Oracle SQL
- SQL*Plus

## Dataset Description
The sample dataset contains the following columns:

- Sale ID
- Product Name
- Quantity
- Price
- City
- Sale Date

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- SUM()
- Aggregate Functions
- TO_CHAR()

## Key Analysis and Findings

1. **Total Revenue:** Calculated the overall revenue generated from all sales.
2. **Best-Selling Product:** Identified the product with the highest total quantity sold.
3. **Product-wise Revenue:** Analysed revenue generated by each product.
4. **City-wise Revenue:** Compared sales revenue across different cities.
5. **Monthly Revenue:** Analysed revenue across different months.
6. **Sales Filtering:** Retrieved individual sales transactions with revenue above ₹10,000.

## Key Findings

- Total Revenue: ₹178,100
- Top Revenue-Generating Product: Laptop
- Highest Revenue-Generating City: Hyderabad
- Highest Revenue Month: January 2026
- Best-Selling Product by Quantity: Mouse

## Project Files

## Conclusion
This project helped demonstrate how Oracle SQL can be used to analyse sales data, calculate revenue, identify top-performing products, and understand sales trends.
